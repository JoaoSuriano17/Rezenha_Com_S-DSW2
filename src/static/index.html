Filmes

Método Descrição Requisição
GET /filmes Retorna uma lista com todos os filmes
GET /filmes/1 Retorna um filme específico
POST /filmes/id/ator/idAtor Adiciona um determinado ator a um determinado filme. Requer idUsuario no corpo da requisição, pois somente os administradores poderão realizar esta operação. {
"idUsuario": 1
};
POST /filmes Adiciona um filme. Requer idUsuario, titulo, diretor, sinopse, faixa_etaria, orcamento e duracao no corpo da requisição. {
"idUsuario": 1,
"titulo": "Avengers",
"diretor": 1,
"sinopse": "Um time de heróis que salvam o mundo diariamente",
faixa_etaria: 16,
orcamento: 100000,
duracao: 200
};
GET /filmes/participa Retorna todos os atores de cada fime
GET /filmes/participa/1 Retorna todos os atores de um filme específico
GET /filmes/maior_participacao/1 Retorna todos os atores com maior participação
DELETE /filmes/id/ator/idAtor Remove um determinado ator de um determinado filme. Requer idUsuario no corpo da requisição, pois somente os administradores poderão realizar esta operação. {
"idUsuario": 1
};

Atores

Método Descrição Requisição
GET /atores Retorna uma lista com todos os atores do sistema
GET /atores/1 Retorna um ator específico
POST /comentarios Adiciona um ator. Requer nome, nascimento, nacionalidade, descricao, qtde_premios no corpo da requisição. { "id":1, "usuario":1, "texto":"...", "post":5 }
PUT /comentarios/33 Altera o texto de um comentário por ID (por exemplo, 33). Requer usuario e texto no corpo da requisição. Somente o usuário proprietário pode fazer a operação. { "id":33, "texto":"novo texto", ... }
DELETE /comentarios/22 Remove um comentário por ID (por exemplo, 22). Requer usuario no corpo da requisição. Somente o usuário proprietário pode fazer a operação. { "msg":"Comentário removido com sucesso" }

Todas as requisições aceitam dados em application/x-www-form-urlencoded
