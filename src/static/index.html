Filmes

Método Descrição/Requisição Resultado
GET /filmes Retorna uma lista com todos os filmes cadastrados. Não requer parâmetros. {
"filmes": [
{
"id": 1,
"titulo": "Fitzcarraldo",
"diretor": 1,
"sinopse": "Um aventureiro tenta construir uma ópera na Amazônia.",
"faixa_etaria": 12,
"orcamento": 100000,
"duracao": 158
}, ...
]
}
GET /filmes/id Retorna um filme específico pelo seu ID. O id deve ser um número maior que 0. {
"filme": {
"id": 1,
"titulo": "Fitzcarraldo",
"diretor": 1,
"sinopse": "Um aventureiro tenta construir uma ópera na Amazônia.",
"faixa_etaria": 12,
"orcamento": 100000,
"duracao": 158
}
}
GET /filmes/participa Retorna todos os filmes e os respectivos atores que participam de cada filme, incluindo o ID, nome e nacionalidade dos atores. {
"filmes": [
{
"id": 1,
"titulo": "Fitzcarraldo",
"atores": [
{
"id": 1,
"ator": "Klaus Kinski",
"nacionalidade": "Alemã"
}, ...
]
}, ...
]
}
GET /filmes/avaliacoes Retorna as avaliações dos filmes cadastradas nas resenhas. Mostra o título do filme e a avaliação atribuída. {
"avaliacoes": [
{
"titulo": "Fitzcarraldo",
"avaliacao": "99.99"
},
{
"titulo": "Agente secreto",
"avaliacao": "7.89"
}, ...
]
}
GET /filmes/id/avaliacao Retorna todas as avaliações de um filme específico. O id deve ser um número maior que 0. {
"id": 1,
"titulo": "Fitzcarraldo",
"avaliacoes": [
{
"idUsuario": 1,
"avaliacao": "99.99"
}, ...
]
}
GET /filmes/resenhas Retorna todas as resenhas relacionadas aos filmes. Mostra o ID do usuário, o título do filme e o texto da resenha. {
"resenhas": [
{
"idUsuario": 1,
"titulo": "Fitzcarraldo",
"resenha": "Lindo filme, nunca vi."
},
{
"idUsuario": 2,
"titulo": "Agente secreto",
"resenha": "Experiência vertiginosa, contagiante."
}, ...
]
}
GET /filmes/id/resenha Retorna todas as resenhas de um filme específico. O id deve ser um número maior que 0. {
"titulo": "Fitzcarraldo",
"resenhas": [
{
"idUsuario": 1,
"resenha": "Lindo filme, nunca vi."
},
{
"idUsuario": 2,
"resenha": "Uma experiência incrível."
}
]
}
GET /filmes/id/ator/idAtor Retorna um ator específico associado a um determinado filme. {
"filme": {
"id": 1,
"nome": "Klaus Kinski",
"nascimento": "1926-10-18",
"nacionalidade": "Alemã",
"descricao": "Ator alemão.",
"qtde_premios": 17
}
}
POST /filmes Adiciona um novo filme. Requer idUsuario, titulo, diretor, sinopse, faixa_etaria, orcamento e duracao no corpo da requisição. Somente usuários administradores podem realizar esta operação. O diretor informado deve existir.

{
"idUsuario": 1,
"titulo": "Avengers",
"diretor": 1,
"sinopse": "Um time de heróis que salva o mundo.",
"faixa_etaria": 16,
"orcamento": 100000,
"duracao": 200
} 		{
"msg": "Filme adicionado com sucesso",
"filme": {
...
}
}
PUT /filmes/id Altera um ou mais atributos de um filme específico. Requer idUsuario e o id do filme. Somente usuários administradores podem realizar esta operação. Os campos titulo, lancamento, sinopse, duracao e orcamento são opcionais. Os campos não enviados permanecem com seus valores anteriores.

{
"idUsuario": 1,
"titulo": "Avengers: Ultimato",
"lancamento": "2019-04-26",
"duracao": 181,
"orcamento": 356000000
} 		{
"msg": "Filme atualizado com sucesso",
"filme": {
...
}
}
PUT /filmes/id/diretor Altera o diretor associado a um filme. Requer idUsuario e idDiretor no corpo da requisição. Somente usuários administradores podem realizar esta operação. O diretor informado deve existir.

{
"idUsuario": 1,
"idDiretor": 2
} 		{
"msg": "Diretor atualizado com sucesso!"
}
POST /filmes/id/ator/idAtor Adiciona um determinado ator a um determinado filme. Requer idUsuario no corpo da requisição. Somente usuários administradores podem realizar esta operação. O ator não pode já estar associado ao filme.

{
"idUsuario": 1
} 		{
"msg": "Associação realizada com sucesso!"
}
DELETE /filmes/id/ator/idAtor Remove a associação entre um ator e um filme. Requer idUsuario no corpo da requisição. Somente usuários administradores podem realizar esta operação. O ator deve estar associado ao filme.

{
"idUsuario": 1
} 		{
"msg": "Dissociação realizada com sucesso!"
}
DELETE /filmes/id Remove um filme específico. Requer idUsuario e senha no corpo da requisição. Somente usuários administradores podem realizar esta operação, e a senha informada deve ser a senha do usuário.

{
"idUsuario": 1,
"senha": "123123"
} 		{
"msg": "Filme e suas respectivas foram deletadas com sucesso!"
}

} 		{ "msg":"Resenha adicionada com sucesso",

PUT /resenhas/id Altera o um ou mais valores de uma resenha por ID (por exemplo, 1). Requer id, idUsuario, idFilme, resenha, avaliacao no corpo da requisição. Somente o usuário proprietário pode fazer a operação. A avaliacao deve ter um valor maior que 0 e que não deve ser maior 100.
{
"id": 1,
"idUsuario": 1,
"idFilme": 1,
"resenha": "Lindo filme, nunca vi.",
"avaliacao": "99.99"
} 		{ "msg":"Resenha alterada com sucesso",
"resenha":[] }
